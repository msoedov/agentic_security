# Contributing

## Procedure

1. Fork the repository on GitHub.
2. Clone your fork:

    ```bash
    git clone https://github.com/<your-user>/agentic_security.git
    ```

3. Install the development dependencies:

    ```bash
    poetry install --with dev
    ```

4. Make a branch for your change:

    ```bash
    git checkout -b feature-name
    ```

5. Make your change. Add tests for the change.
6. Run the tests:

    ```bash
    pytest
    ```

7. Commit the change and push the branch to your fork.
8. Open a pull request to `msoedov/agentic_security`.

## Code of conduct

Obey the [Code of Conduct](https://github.com/msoedov/agentic_security/blob/main/CODE_OF_CONDUCT.md).
